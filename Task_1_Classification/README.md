# Task 1: Iris Flower Classification

## Project Overview
This project uses supervised machine learning to classify Iris flowers into three species:
- Setosa
- Versicolor
- Virginica

## Dataset
- Dataset: Iris Flower Dataset
- Total Records: 150
- Input Features: 4
- Target Column: species

## Algorithms Used
1. Logistic Regression
2. Decision Tree Classifier

## Data Preprocessing
- 80% training data
- 20% testing data
- StandardScaler for feature scaling

## Model Performance

| Model | Accuracy |
|---|---:|
| Logistic Regression | 93.33% |
| Decision Tree | 93.33% |

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Technologies Used
- Python
- Pandas

- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Files

## Conclusion
Both Logistic Regression and Decision Tree achieved 93.33% accuracy on the test dataset.
